# callsong

Generative animal-call synthesis: a configurable **nonlinear syrinx** rendered
in JAX, whose instrument space is **illuminated by MAP-Elites** using the first
two PCA axes of **BirdNET embeddings** as behaviour descriptors.

The premise (after Mindlin, *The physics of birdsong production*): the syrinx is
a low-dimensional nonlinear oscillator driven by a slow motor gesture
(air-sac pressure `α`, syringeal tension `β`). Its bifurcations — onset,
harmonic stacks, subharmonics, period-doubling, chaos — are exactly what make a
call sound alive. Rather than backpropagate a neural ODE at sample rate, we
keep the model **forward-only** and search it evolutionarily.

## Pipeline

```
genome (instrument) ───┐
                       ├─► JAX render ─► BirdNET embed ─► PCA(2) ─► archive cell
CPG gesture bank ──────┘        │                                      ▲
 (illuminated, fixed)           └─► acoustic fitness ──────────────────┘
                                    (nonlinear richness, anti-degeneracy)
```

- **`callsong/synth.py`** — generalised limit-cycle source + trachea reflection
  comb + 2-formant state-variable band-pass bank + aspiration noise + tanh
  saturation. One `lax.scan`, oversampled, `vmap`-ed over the population. The
  default genome reproduces the Rust reference (`rust/birdsong`); genome gains
  `k_cub, k_sq, k_sqy, k_xy` deform the vector field, moving its
  bifurcation structure.
- **`callsong/gestures.py`** — the motor score, generated by a **vocal CPG**
  rather than drawn from splines. A Wilson–Cowan excitatory/inhibitory rate
  pair, forced by a periodic "HVC" burst clock, is the mechanistic model behind
  Alonso *et al.*'s result that canary air-sac pressure patterns are the
  *subharmonic solutions of a forced normal form* — a small discrete set of
  shapes, not a continuum. Syllable onsets and silences are therefore
  **emergent**: α crosses the phonation onset because of the CPG's own
  relaxation dynamics. β reads out a *lagged* copy of the same activity (the
  sign of the lag makes a syllable up- or down-swept), following the
  pressure↔envelope / tension↔f0 correspondence found when real song is
  inverted. The same model in its relaxation regime covers anuran pulse trains
  (20–60 pulses/s). The gesture is a *probe*, not part of the genome.
- **`callsong/genome.py`** — 30-parameter genome in normalised `[0,1]` space:
  16 instrument + 14 CPG gesture. A genome is a whole *performance*, so each
  renders exactly one call rather than being swept by a shared bank.
- **`callsong/features.py`** — fitness = audibility · tonality ·
  (spectral-contrast + spectral-flux). The first two are *gates* (silence,
  white noise); the last two are the reward, and both are mapped affinely from
  their measured range onto `[0,1]` — see the calibration note below.
- **`callsong/birdnet.py`** — BirdNET 1024-D embeddings (via `tensorflow-cpu`,
  off the GPU) + the 2-D PCA descriptor projector.
- **`callsong/archive.py`** — MAP-Elites grid over the PCA descriptor space.

## Run

```bash
# hear the physics: an α ramp through the phonation onset at 3 tensions
uv run python scripts/demo_bifurcation.py            # -> _demo/*.wav, *.png

# map the phonating region / f0 range of the source (provenance for the bounds)
uv run python scripts/probe_phonation.py

# check the fitness terms still discriminate (none saturated)
uv run python scripts/calibrate_fitness.py

# audition a run: whole spectrogram per call, cursor sweeping, arrows to step
scripts/wavspec                       # newest outputs/*/calls/
scripts/wavspec <dir> --waves         # waveform view
scripts/wavspec <dir> --live          # scrolling spectrum, no pre-render

# re-render calls + plots from a saved archive (e.g. an interrupted run)
uv run python scripts/render_archive.py --select spread   # or --select top

# illuminate the instrument space
uv run python run_mapelites.py                       # -> outputs/<ts>/
uv run python run_mapelites.py generations=300 offspring=32 archive_resolution=32

# (optional) ground the descriptor axes on REAL recordings, then use them
uv run python scripts/fit_projector.py --audio_dir ~/sounds --out projector.npz
XC_API_KEY=... uv run python scripts/fit_projector.py --xc \
    --groups birds,frogs,grasshoppers --per_group 80 --out projector.npz
uv run python run_mapelites.py projector_path=projector.npz
```

Each run writes to `outputs/<timestamp>/`: `archive.npz`, `projector.npz`,
`gestures.npz` / `gestures.png` (the CPG bank and its own archive),
`archive_scatter.png`, `top_calls.png`, and `calls/*.wav` (the highest-fitness
elite per top cell, re-rendered).

## Notes / knobs

- **Gesture illumination.** The bank is not sampled, it is *illuminated*:
  `gesture_candidates` CPG parameter sets are swept, dropped into a
  (syllable rate × tension sweep) archive keeping the best probe per cell, and
  `n_gestures` elites are picked by farthest-point sampling. So the bank is
  diverse by construction — sustained glides, rhythmic phrases and 40–60 Hz
  trills all appear — and, being seeded, identical for every instrument and
  across runs. Costs ~15 s once per run; `gestures.png` shows what it picked.
- **Phonating region.** `ALPHA_*`/`BETA_*` in `gestures.py` were measured
  against the model with `scripts/probe_phonation.py`, not transcribed:
  α ≲ 0 is silent for every β, onset sits near α ≈ +0.02, and β drives the
  fundamental monotonically from ~310 Hz to ~6.3 kHz over `[0, 2.6]` — the
  range Boari *et al.* need (0.002 < β < 2.99) to cover zebra finch f0.
  Published normal forms differ in how they absorb the signs of α and β, so
  re-run the probe if the source vector field changes.
- **Fitness calibration.** A reward term whose normaliser saturates stops
  ranking anything. Spectral flux was originally scaled `×20`, but the flux
  measure is already in `[0,1]` by construction (each spectral column is
  normalised), so it clipped to exactly 1.0 for **every** call and fitness
  quietly reduced to the contrast term alone. Both terms are now affine maps of
  their measured range (`contrast` 9–20 dB, `flux` 0.08–0.34), which takes
  contrast's spread from σ=0.065 to σ=0.168 and flux's from σ=0 to σ=0.201.
  `scripts/calibrate_fitness.py` re-derives the anchors and reports the
  saturation of every term; re-run it if the source model or gesture bank
  changes. (`audible` reads as 100% saturated and should: calls are
  peak-normalised, so anything that makes a sound clears the silence gate.)
- **Auditioning a run.** Take a *spread* of elites, not the top-k. Fitness is
  one scalar and its extreme tail concentrates: on this run, 14 of the top 24
  calls shared a single dominant AM rate (12.3 Hz) and two thirds came from one
  gesture, so the archive's whole point was being discarded at the output step.
  `render_archive.py --select spread` farthest-point-samples the descriptor
  space instead, which drops the most-common rate's share from 58% to 42%. The
  remaining concentration is the gesture skew below, not the selection.
- **Gesture skew (open).** Two of the six probes win 81% of archive cells
  (g1 at 12.7 mod/s, g4 at 72.7). Cells go to whichever (instrument, gesture)
  pair scores highest, and dense fast gestures score well on flux, so slow and
  sustained probes rarely win anywhere. The bank is diverse; the archive is not.
  Fixing it properly means putting `gesture_id` in the cell key (rate x PC1 x
  PC2) or ranking fitness within each gesture — both are design changes.
- **Throughput.** The `scan` is sequential in time (~4 s wall for a 3-s call at
  48 kHz, OS=6) but parallel across the batch, so a whole generation renders in
  one `vmap`. BirdNET (~77 ms/call, CPU) is the real bottleneck.
- **Descriptor grounding.** PCA is fit on a bootstrap random population by
  default. `scripts/fit_projector.py` instead fits it on real recordings —
  a local folder and/or Xeno-canto across taxa (birds + frogs + insects), so
  the axes span a wide cross-taxa timbral gamut. Xeno-canto API v3 needs a
  personal `XC_API_KEY` (required for downloads since 2025-10-10). BirdNET is
  bird-trained but still embeds any audio, so frog/insect clips project fine.
- **GTX 1650 (4 GB):** `XLA_PYTHON_CLIENT_PREALLOCATE=false` and
  `MEM_FRACTION≈.6` (set by the scripts); BirdNET stays on `tensorflow-cpu`.
- Fitness weights, archive resolution, gesture count, and generation budget are
  all in `conf/config.yaml` (Hydra overrides on the CLI).
